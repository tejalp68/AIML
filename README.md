# AIML

A daily log of what I'm learning in my AI/ML course — notes, code, and small experiments, added as I go.

## About

This repo is my running journal for an AI/ML course. Instead of one big dump at the end, I'm committing something (however small) after each day of learning: notes, code snippets, mini exercises, or links to resources that helped.

## Structure

Organized by date/topic so it's easy to track progress over time:

```
AIML/
├── README.md
├── DAY01/
│   ├── day01.md
│   └── day01.ipynb
├── DAY02/
│   ├── day02.md
│   └── day02.ipynb
└── .....
```

## Goals

- Build a consistent daily learning habit
- Keep a searchable record of concepts, code, and gotchas
- Track progress from fundamentals to more advanced ML/AI topics


*Consistency over perfection — a little bit every day.*
